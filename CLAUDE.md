# Analysis of Unstructured Data: problem sets

- `materials/`: lecture PDFs and `AUD_Lab_assignments.pdf` (all problem sets).
- `listNN/`: one self-contained uv project per problem set. `list01/` is the reference.
- For any work on a list, load the `aud-problem-set` skill (`.claude/skills/aud-problem-set/`)
  and follow it: logic in `listNN/src/`, presentation in `listNN/listN.ipynb`.
- Windows machine: use `pathlib`; run everything with `uv run` from inside `listNN/`.
- Do not `git commit` unless asked.
